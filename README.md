# Henna Spring Website

A static, responsive, single-page website for Henna Spring, an organic henna shop and bridal Mehedi artist based in Gazipur, Bangladesh.

## Project Features
* Built with HTML5, CSS3, and Vanilla JavaScript.
* Fully responsive and mobile-first design.
* WhatsApp order integration.
* Custom bKash payment modal with copy-to-clipboard functionality.
* Optimized for direct hosting on GitHub Pages.
